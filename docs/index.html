價格是虎航官網日曆上當天最便宜航班的票價（新台幣），未含稅金與附加費用。 tigersmart、tigerpro 是用實際查到的固定加價估算（每段 +$950、+$1,600）。 「含稅約」是用各航線實際查過一次的「稅金與其他費用」估算，會因旺季、匯率、燃油附加費調整而有出入。 價格變化是每天記一次當天看到的最低價，「比昨天」就是和前一天的最低價比較。實際以 虎航官網訂票頁為準。 資料每小時由 GitHub Actions 自動更新。
